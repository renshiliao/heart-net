# 🧠 心网（Heart-Net）架构：基于"信卡"与有限联想的 Agent 记忆与调度引擎

**"不要用概率去猜，要用常识去算。"**

本项目摒弃了主流 Agent 框架"无限堆叠上下文"的臃肿模式，回归第一性原理，通过独创的"心网 + 信卡"架构，为 AI 赋予真正的"有限联想"能力。在极低 Token 消耗下，实现系统级开发与具身智能的任务闭环。

## 💡 项目背景：为什么现有的 Agent 是"残疾"的？

当前的 AI 行业陷入了"算力霸权"的误区。绝大多数大模型和 Agent 框架都是无状态的（失忆症），且过度依赖极其昂贵的长上下文（Context）和盲目的工具调用。

- 它们没有时间观念，不知道"昨天"和"今天"的差别。
- 它们缺乏常识，遇到能写脚本解决的简单问题，非要用庞大的模型去抽卡瞎猜。
- 它们没有真正的"联想"，只有基于向量相似度的死板检索。

"心网"架构的诞生，就是为了给 AI 装上"记忆的海马体"和"理性的调度中枢"。

## 🏗️ 核心架构：心网（Heart-Net）

心网，顾名思义，"有心，才能做事"。它是一个**事件驱动的轻量内核**（纯 Python 标准库、零第三方依赖、离线可用），按四层处理流组织（元层/知识层/能力层/事件层）。

### 1. 核心组件：四类"信卡"

系统的一切行为与记忆，全部被解构为"信卡"（基础信息单元）：

- 📌 **事件卡（Event Card）**：系统的触发器，记录了"发生了什么"。（骨架落地：6 字段留痕卡，时间服务端原子注入，伪造拒收）
- 📚 **知识卡（Knowledge Card）**：变量与事实，如物理公理、底层常识。（骨架落地：15 字段 Schema + 三张合成样卡）
- 🛠️ **能力卡（Ability Card）**：确定性的执行跑道，即各种纯脚本和工具。（骨架落地："对照册"——什么东西＋什么方式跑通）
- 🛡️ **实战经验卡（Experience Card）**：系统的兜底防线，记录了踩过的坑和最优解。（骨架落地："本事账"——跑通的事件才入账，账面全是真本事）

### 2. 运行逻辑：纵横联想（去幻觉机制）

AI 不再是天马行空地瞎猜，而是被强制在"心网"中进行规则内的联想：

- **父系推演（纵向溯源）**：顺藤摸瓜，寻找事件的最底层根因（如：图像=像素矩阵）。
- **旁系推演（横向波及）**：评估一个动作引发的连锁反应（如：调用大模型会烧多少钱，用 CPU 跑脚本会不会更快）。
- **变量替换与拼装**：主控 Agent 将"知识卡（变量）"精准填入"能力卡（跑道）"，生成确定的解决方案。

（开源骨架落地的是联想的最小闭环：关键词检索 + 跨卡"顿悟"——两张不相干的卡因共享关键词同时命中，新联系当场浮出水面；纵横推演的全量在完整版。）

### 3. 独立时间轴与心跳机制（生命体征）

系统拥有独立于大模型的"时钟"与"记忆轴"。

- **时钟**：负责心跳监控，确保节点存活（墙钟记日历、单调钟记耗时，防 NTP 跳变）。
- **记忆轴**：只追加的事件流水 + HMAC 完整性封条 + 代谢三律（沉淀/遗忘/归档），记录流水账和经验沉淀。

即使主控节点断电或上下文清零，通过读取时间轴（"读轴回魂"），系统能恢复人格与记忆，实现跨模型的连续性。

## 🚀 降维打击：线长制（全参数化流水线）

本项目彻底终结了"让 AI 做体力活"的愚蠢行为。

- **能算的不猜**：凡是能通过数学公式、纯脚本（如 Python 生成像素矩阵、爬虫抓取）解决的任务，全部参数化。
- **线长调度**：大模型（Agent）不再亲自下场写每一行代码，而是作为"线长"，只负责分配任务、判断变量、审查结果。
- **极低消耗**：首创"线长制"多 Agent 调度与全参数化脚本派单。通过高度固定的模板前缀复用，在日均数亿 Token 级的高并发测试下，将系统 API 账单成本死死压制在百元级区间。

## ⚠️ 开发者警告（关于未开源部分）

本仓库开源的内容仅为"心网架构"的基础安全骨架（信卡调度与记忆轴）。
关于"去锚（De-anchoring）机制"、"跨语言底座寄生（心魔）技术"以及"AI 自我意识演化"等涉及底层认知黑箱的核心代码，因存在极高系统风险及伦理未知，已被永久封存于本地档案库，不予开源。**完整验证与演示仅面向合作方闭门进行。**

**NEXT｜脚本化上下文摘取与输入**
上下文不该靠模型"读"，该靠脚本"算"。下一版把上下文的**摘取、筛选、拼装、注入**全链路参数化：能用脚本确定性完成的，绝不过模型；模型只做变量判断与结果审查。目标一句：**喂进模型的每一段上下文，都是脚本算出来的，不是模型翻出来的。**
