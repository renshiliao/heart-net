# mzy-oss

**给 AI 装上记忆和时间感的轻量框架。** 纯 Python 标准库，零第三方依赖，离线可用，Apache-2.0 开源。

## 这是什么

**给学生党一个『学了不白学』的知识收纳引擎。** 目标用户：学生——考试、考证、上课、自学都算。痛点人人有：学了就忘、重点抓不住、笔记散乱。卖点是**知识单元卡**：把知识拆成「可检索、可换绑、可复用」的小卡。学一科攒一叠卡，考前喊号检索重点，学过的东西只要跑通了就自动进「本事账」——不白学，是你能带走的底气。

**进阶叙事（写给进阶用户）：这是具身智能的门票。** 有记忆才有连续性，有连续性才有自我，有自我才配走进具身硬件——本框架把「记忆 + 时间」做成了可拆卸的标准件。外加一句名利叙事：有名才有利，有人重视才是起步；开源露真本事，才是被重视的起点。

## 核心概念

### 三件套

- **时钟内核（m1_clock）**：持久化任务库 + 唤醒线程 + 错峰补跑。五字段 cron（周日 0/7 兼容）、interval 相对计时器、date 一次性触发三类触发器；先写库再注册调度，崩溃重启任务不丢；宽限内漏跑自动补，超宽限记「错过」留痕；同任务并发上限防堆积；双钟分工——墙钟记日历、单调钟记耗时，防 NTP 跳变。
- **记忆时间轴（m2_axis）**：只追加的事件流水 + HMAC 完整性封条 + 代谢三律。外部绕程序直改轴文件，校验当场失败暴露。
- **事件卡（功能语说明）**：记录「发生过什么」的六字段留痕卡（ts/time_source/source/status/content/sha），时间由服务端原子注入，调用方伪造一律拒收。

### 心网四层处理流（真名直书，这就是卖点）

| 层 | 干什么 | 为什么值得要 |
|---|---|---|
| **元层** | 检查与把关 | 入库前先审，垃圾进不了门 |
| **知识层** | 知识变量与卡片 | 知识拆成小卡，可检索、可换绑、可复用 |
| **能力层** | 跑通的本事跑道 | 什么东西＋什么方式跑通，记在对照册 |
| **事件层** | 事件跑通才计入本事账 | 没跑通的不算数，账面全是真本事 |

### 代谢机制（记忆整理 = 沉淀 + 遗忘 + 归档）

活跃区像活物：事件涌入会变大，代谢后又缩小。**沉淀**——临时件提炼成卡件归档降重；**遗忘**——垃圾判据命中才清、逐条留痕可查，不盲删；**归档**——完事事件进档案馆长存，永不参与遗忘。全挂在心跳上，自动运转。

### 顿悟机制

跨卡相撞冒出新连接：检索时两张不相干的卡因为共享关键词同时命中，新联系当场浮出水面；跑通的事件自动沉淀进本事账。

## 快速开始

```bash
python3 demo/run.py
```

一条命令跑通最小实例：**离线、零配置、零 API key**，输出五个现象并逐条标注「你在看什么」。数据留在 `demo/data/`，跑完不删，欢迎开箱验货。

安装到本地（零网络，装的全是包内自带文件）：

```bash
./install.sh            # 缺省装到 ./installed
./install.sh /opt/myapp # 或指定目录
```

心跳常驻：

```bash
MZY_OSS_DATA=./data/axis python3 live.py   # 缺省数据目录 ./data/axis
```

## 五工具契约

| 工具 | 参数 | 返回 | 错误语义 |
|---|---|---|---|
| `xw_search(query, top_k=5)` | `query` 关键词（支持多词）；`top_k` 上限 | 命中列表 `[{id, title, trigger, snippet}]` | 无命中**显式返回空列表 +「无卡」**，零空手 |
| `xw_card_get(id)` | `id` 卡号 | 整卡（15 字段） | 不存在显式 `{"error": "not_found", "id": ...}` |
| `xw_event_log(content, source, status)` | 事件内容 / 来源 / 状态 | 事件卡 `{ts, time_source, source, status, content, sha}` | 调用方传入的时间字段（含嵌套）**一律递归拒收**，错误语义 `time_field_rejected` |
| `xw_status()` | 无 | `{events, cards, integrity_ok, runtime_sec}` | 运行状态错误原样显式呈现；本接口不提供权威时间 |
| `xw_time()` | 无 | `{now_iso, now_human, time_source}`，`now_iso`/`now_human` 带星期几 | 不接受调用方时间参数；时间来源恒为 `server` |

**时间契约四条**（铁律，谁破谁背锅）：

1. 调用方伪造时间字段一律拒收（递归检查，`time_field_rejected`）；
2. 时间由服务端原子注入，写进事件卡；
3. `xw_time()` 是唯一取时口；
4. 墙钟记日历、单调钟记耗时——两钟分离，防 NTP 跳变把超时判定带偏。

## 卡格式 Schema

### 知识卡·对外版（15 字段）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 卡唯一标识，如 `card-math-trig` |
| `title` | string | 卡标题 |
| `trigger` | string | 检索触发词，`\|` 分隔 |
| `keywords` | array\<string\> | 关键词列表 |
| `content` | string | 卡正文（Markdown 纯文本） |
| `category` | string | 学科分类，如 `数学` |
| `source` | string | 来源相对路径，如 `notes/math-trig.md` |
| `confidence` | number | 置信度 0~1 |
| `created_at` | string | 创建时刻（ISO 8601） |
| `updated_at` | string | 更新时刻（ISO 8601） |
| `revision` | integer | 修订号 |
| `parent_revision` | integer \| null | 上一修订号，首版为 null |
| `change_type` | string | 变更类型，如 `created` / `updated` |
| `version` | integer | 版本号 |
| `content_sha256` | string | `content` 的 sha256 前 16 位（真算不编） |

对应 `samples/` 三张合成样卡：三角函数公式速查、英语时态口诀、HTTP 状态码三连。

### 事件卡·对外版（6 字段）

| 字段 | 类型 | 说明 |
|---|---|---|
| `ts` | string | 事件时刻，对表格式含星期几，服务端原子注入 |
| `time_source` | string | 时间来源，恒为 `server` |
| `source` | string | 事件来源标识 |
| `status` | string | 状态：`进行中` / `已完成` |
| `content` | string | 事件内容 |
| `sha` | string | `content` 的 sha256 前 12 位 |

可选扩展字段：`event_id`、`tags`、`content_sha256`。

## 安全承诺

安全承诺只保留三项不泄内容；其余能亮就亮：

- 密钥与账号密码不出；
- 内部事故原文不出；
- 个人身份真名不出。

另有三条硬承诺：

1. **对外零留痕**：对外管道不落盘、不留痕，代码即承诺（`external_pipe.py` 连数据目录都不接，活证见 demo 现象⑤）；
2. **数据全本地**：所有记忆都躺在你自己的磁盘上，不上传、不同步、不联网；
3. **开源免费 Apache-2.0**：当前发布物免费采用 Apache-2.0，样例卡全为合成脱敏件，不抄任何真实卡。

## 教学场景

老师用它整理教学重点：一章一叠卡，学期末喊号检索就是现成的复习提纲。学生用它建自己的知识库：上课、刷题、考证随手记，跑通的自动进本事账。教材类知识卡随便上——公式、定理、语法口诀、状态码表，越碎越好检索。

## 保险声明

- **默认内置保护机制**：计量表、日限额 + 熔断、脚本巡检、撞墙熔断；这些机制默认装着，保护的是你。
- **自行拆除保险**：如果你拆除保险并全量放开，后果自行承担。
- **责任边界**：只对装着保险时的体验负责，不对拆掉保险后的账单负责。

面向所有人：聪明人要自由（骨架可魔改），要安全的有兜底（默认保护烧不穿）；下限靠设计兜住，上限留给用户。
